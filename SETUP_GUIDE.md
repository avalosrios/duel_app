# Setup Guide

## Prerequisites

| Tool    | Version           |
| ------- | ----------------- |
| Node.js | 24.3.0            |
| npm     | 11.4.2            |
| Docker  | Latest (optional) |

Use [nvm](https://github.com/nvm-sh/nvm) or [fnm](https://github.com/Schniz/fnm) to manage Node versions. The `engines` field in `package.json` pins the exact versions.

## Local Development (no Docker)

```bash
# From the repo root
cd client

npm install
npm run dev
```

Dev server runs at `http://localhost:5173` with HMR enabled.

## Docker Compose

Spins up the app behind a Traefik reverse proxy on port 80.

```bash
# From the repo root
docker compose up
```

App is available at `http://localhost`.

For auto-reload during development (syncs source files into the container):

```bash
docker compose watch
```

## Other Useful Commands

```bash
# Type check (generates react-router types then runs tsc)
npm run typecheck

# Lint
npm run lint

# Format
npm run format

# Production build
npm run build

# Serve the production build locally
npm start
```

## TypeScript Path Aliases

Two aliases are configured in `tsconfig.json`:

| Alias      | Resolves to            |
| ---------- | ---------------------- |
| `~/`       | `./app/`               |
| `~router/` | `.react-router/types/` |

Always use `~/` instead of relative imports when referencing app code. Example:

```typescript
// Good
import { playersAtom } from "~/game/state/atoms";

// Avoid
import { playersAtom } from "../../state/atoms";
```

## Building for Production

```bash
npm run build
npm start
```

Or build and run the Docker image directly:

```bash
docker build -t duel-app .
docker run -p 3000:3000 duel-app
```

## Notes

- The backend service is commented out in `compose.yml` — the app is currently frontend-only.
- `.react-router/` contains auto-generated types. Don't edit those manually; they're regenerated by `npm run typecheck`.
- `build/` and `coverage/` are gitignored. Run `npm run build` or `npm run test:coverage` to generate them locally.
